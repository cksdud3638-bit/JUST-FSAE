# 주행 테스트 관리 통합

## 화면과 작업 흐름

상단의 랩타임 기록, 테스트 일지, 드라이버 피드백을 `2 주행 테스트 관리`로 통합했다. 연료 전략은 3번으로 유지하고 이후 메뉴 번호를 정리했다. 기존 홈 바로가기 이름(laptime/testlog/feedback)은 해당 내부 화면으로 연결된다.

공통 테스트 선택과 드라이버 필터, 랩 수/유효 랩 수/최고/평균/피드백 요약 아래에 네 작업 화면을 둔다.

- 테스트 정보: 이름·장소·목적·날짜·날씨·노면·결과·문제·다음 조치. 차량 세팅과 냉각/운행/연료 데이터는 펼쳐서 입력한다.
- 랩타임: 선택한 테스트와 조건을 기본 연결하고 연속 입력 시 드라이버·타이어·세팅을 유지한다. 기존 랩의 수정 및 연결 변경을 지원한다.
- 피드백·세팅: 테스트 및 개별 랩에 피드백을 연결한다. 랩 선택 시 드라이버·날짜를 가져온다. 피드백과 세팅 이력의 목록·편집·삭제를 지원한다.
- 테스트 비교: 두 테스트를 명시적으로 선택해 조건/세팅/결과와 동일 드라이버의 유효 랩 및 피드백을 비교한다. 날짜만으로 연결이나 인과관계를 추정하지 않는다.

전체 및 미연결 범위를 제공한다. 테스트에 연결되지 않은 기록과 삭제된 테스트를 참조하는 기록은 미연결 범위에 남으며 편집으로 재연결할 수 있다.

## 데이터 보존과 저장

기존 `testLogs`, `lapTimes`, `feedbacks`, `setupHistory` 저장 경로를 유지한다. 기존 숫자 ID와 문자열 ID를 비교할 때만 정규화하며 실제 ID와 `sessionId`, `testLogLink`, `setupLink`를 변경하지 않는다. 새 피드백의 `lapId`, 새 테스트의 title/location/purpose 및 저장 시각은 추가 필드다. 구형 필드와 setup/cooling의 추가 속성을 보존한다.

읽기 시 Firebase 배열/희소 객체를 목록으로 해석한다. 화면 진입만으로 기존 데이터를 다시 쓰거나 날짜 기준으로 병합하지 않는다. 저장은 서버의 최신 상태에서 해당 기록 하나를 변경하는 트랜잭션으로 처리한다. 다른 사용자가 추가한 기록과 관련 없는 컬렉션을 유지하고, 삭제된 레코드의 편집은 오류로 알린다. 저장 중에는 입력을 잠시 잠그고 실패 시 기존 상태와 입력을 유지한다.

테스트 삭제 시 랩·피드백·세팅 기록은 연쇄 삭제하지 않는다. 연결된 랩의 드라이버/테스트를 바꾸려면 피드백의 랩 연결을 먼저 해제해야 한다. 랩을 삭제해도 피드백은 남는다. 전체 JSON 저장/불러오기에는 기존 경로와 연결 필드가 그대로 포함된다.

## 함께 수정한 오류

- 무효 랩만 있는 드라이버에게 무효 기록을 ‘유효 최고기록’으로 표시하던 문제를 제거했다. 요약·표·차트·홈 모두 유효하고 해석 가능한 랩만 통계에 사용한다.
- 초가 60 이상인 시간과 0초 기록을 거부하고 밀리초 반올림이 분을 넘어갈 때 올바르게 표시한다.
- 이전 테스트 비교에서 실제 객체 대신 문자열을 읽던 문제를 제거했다.
- 날짜만으로 서로 다른 드라이버의 피드백을 세팅 효과로 묶던 자동 비교를 제거했다.
- 좋음 점수와 언더/오버스티어 심함 점수를 같은 종합점수로 더하지 않는다. 이전 평가값은 보존하며 목록에서 확인할 수 있다. 새 차트는 명시적인 7개 평가 항목이 있는 기록을 사용한다.
- 사용자 입력은 목록에서 HTML로 해석되지 않도록 처리한다.

## 검증

`node --test tests/*.test.cjs`: 92개 통과. 기존 기능 회귀와 함께 숫자/문자 ID 및 희소 목록, 같은 날짜의 독립 테스트, 무효 랩 통계, 기존 속성 보존, 삭제 후 미연결 접근, 연결 무결성, 동시 갱신 재시도, 저장 실패, 시간 순서, 메뉴/ID 구조를 검사한다. 실제 공통 백업 내보내기/불러오기 테스트에도 테스트·랩·피드백·세팅 연결과 구형 속성의 왕복 보존을 추가했다.

Firebase를 대체한 로컬 화면에서 테스트 A/B 생성, 랩 및 피드백 연결, 무효 랩 제외, 기록 편집, 세팅 이력 저장, 새로고침 후 유지, 미연결 랩의 재연결을 확인했다. A의 1:23.456과 B의 1:21.000이 같은 드라이버의 평균 차이 -2.456초로 표시되고 공기압 80→85kPa 및 피드백이 함께 표시되는 것을 확인했다. 모바일 390px에서 가로 넘침 및 중복 DOM ID가 없고 콘솔 오류가 없었다. 운영 데이터에 검증용 기록을 쓰지 않았다.

비교 결과는 주행 조건이 같은 실험이라는 보증이나 세팅 효과의 인과 추정이 아니다. 구형 피드백의 다른 평가 체계는 새 평가로 자동 변환하지 않는다.
