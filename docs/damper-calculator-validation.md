# 댐퍼 계산기: 상수 출처와 검증 기록

검토일: 2026-09-10. 공식 저장소 cksdud3638-bit/JUST-FSAE, main. 기존 GitHub Pages 자동 배포(pages-build-deployment)를 유지한다.

## 근거 검색

저장소 전체 파일과 원격 main 트리, damper.js 변경 이력을 확인했다. 현재 저장소에는 HTML/CSS/JavaScript만 있으며 실차 측정표, CAD, 스프링 시험표, 다이나모 시트, 댐퍼 모델 설명서는 없다. 기존 수치는 4c51581의 damper.js(v2)에서 계승했으나 실차값이라는 증거는 아니다. S.cornerWeights는 런타임 측정 입력 저장 구조이며 값의 측정 조건·운전자/유체 포함 여부는 스키마에 없다. 따라서 불러오기는 읽기 전용으로 수행하고 조건 확인 안내를 표시한다.

분류: ① 수학·단위변환 / ② 실차·CAD 고유값 / ③ 댐퍼·다이나모 고유값 / ④ 설계 목표·모델 가정. 공학 값과 별개인 구현 한도·문구는 아래에 별도로 기록한다.

## 구현 결정과 한계

- 질량: 축 평균 간편 모드. 네 코너 측정값을 불러오되 축별 평균으로 변환한다. 운전자·유체 포함 여부는 원본 저장 스키마에 없어 사용자 확인 안내를 표시한다. 코너별 비대칭 현가 해석은 구현하지 않았다.
- 전후 스프링은 독립 입력. MR은 정적 차고 부근 선형화 가정이다. 코너별 MR/스트로크 곡선은 자료가 없어 추가하지 않았다.
- 타이어 강성 자료가 없으므로 입력 숫자를 만들지 않고 결과를 '타이어 강성 미포함 근사 라이드 주파수'로 명시했다. ARB는 제외 상태를 결과·복사에 표시하며 총 롤 강성이라고 부르지 않는다.
- 공통/별도 다이나모 모드 지원. 각 데이터 세트에 모델, 온도, 가스압, 속도, Hard/Soft 방향별 힘, 클릭 기준, 측정일/출처, 다른 조절기 위치를 기록한다. 속도 변경 시 힘 재확인 경고가 강화된다. 입력 출처 기록 자체가 실측 검증을 보증하지 않는다.
- 실제 조절 방식의 기본값은 unknown. 선택 전 클릭 계산은 보류. 2-way는 두 속도 교집합, 3-way는 압축 두 조절기+공통 리바운드, 4-way는 각 방향/속도별 별도 조절기를 계산한다. 분리 조절기 총 클릭에는 임의의 기본값을 만들지 않았다.
- 끝점 선형 보간과 3/4-way 조절기 독립성은 근사 가정이다. 교차 영향이나 비선형 클릭 곡선은 모델링하지 않는다. 향후 클릭별 CSV는 데이터 세트별로 source와 실제 측정점 배열을 추가해 확장할 수 있으나 이번에는 자료·포맷 근거가 없어 importer를 만들지 않았다.
- ζ_eq는 해당 샤프트 속도에서 F/V로 구한 secant 등가값. 가스력·마찰·히스테리시스가 포함되면 오차가 생긴다. 실제 언더/오버스티어는 롤 강성만으로 확정하지 않는다.
- 저장 스키마는 그대로다. 계산기 입력과 메타데이터는 세션 내에서만 유지되며 결과 복사에 포함된다. Firebase를 읽는 코너웨이트 가져오기는 쓰기를 하지 않는다.

## 검증

자동 검증: node --test tests/damper.test.cjs (48개). 모든 js 파일 node --check 및 git diff --check. 기본값 전체 현가질량 242.670 kg, 코너 전 60.6105/후 60.7245 kg, 휠 레이트 13.65525/18.90000 N/mm, 주파수 2.388889/2.807819 Hz, Ccrit 1.819507/2.142609 N·s/mm, 롤 강성 9.831780/13.158180 ×10⁶ N·mm/rad, 전륜 비율 42.7655%.

테스트는 이전 경계값 6종 외에 축별 스프링 독립성, 코너웨이트 불러오기와 비변경, 공통/별도 모드, 3/4-way 클릭 필수 검증·분리 계산, 메타데이터 검증·복사, 미확인 구조의 계산 보류를 포함한다. 테스트용 Firebase/JSON 저장 왕복을 사용하며 운영 데이터를 쓰지 않는다.
