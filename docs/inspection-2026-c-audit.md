# 2026 C-Formula 인스펙션 점검 및 대회 날짜

## 대조 기준

사용자 제공 `[규정] Formula 차량기술규정(2026) (1).pdf` 63쪽, 2025.12.18 시행본을 대조했다. 공통/내연기관 제3~36조와 공통 제69~79조, SEF 부록을 대상으로 했다. 제37~68조 및 공통 장 안의 전기차 전용 세부 항목은 제외했다. 외부 최신판으로 대체하지 않았다.

기존 199개 ID를 모두 유지하고 104개를 추가해 26분류 303개 항목으로 정리했다. 기존 25개 항목은 기준을 수정하고 `2026-09-C` 재확인 대상으로 지정했다. 장비 사용 조건에 따라 ‘해당없음’을 선택할 수 있고, 해당없음은 통과율 분모에서 제외한다. 전자식 스로틀 제36조는 내연기관 규정이므로 ETC 사용 시에만 적용한다.

## 기록 및 날짜 처리

- 기존 점검 상태와 메모는 삭제하지 않는다. 수정 항목의 과거 통과는 화면/보고서에서 확인중으로 표시하고, 다시 통과를 선택하면 상태와 확인 버전을 한 번에 저장한다.
- 홈의 ‘대회 날짜’에서 저장/삭제할 수 있으며 인스펙션 보고서 날짜 입력과 같은 저장 경로를 사용한다. 실제 날짜는 입력하지 않았다.
- 날짜만 저장하고 한국 시간의 달력 날짜로 D-Day를 계산한다. 자정/탭 복귀 시 갱신한다. 전날 D-1, 당일 D-Day, 다음 날 D+1이다.
- 전체 JSON 백업에 날짜와 재확인 버전을 포함한다. 구형 백업에 없는 대회 날짜는 유지하고, 구형 점검 상태를 가져오면 수정 기준을 재확인한다.
- CSV에 적용조건·실효 상태·기존 상태·확인 버전을 포함한다. 인쇄 보고서도 같은 통과율과 날짜를 사용한다.
